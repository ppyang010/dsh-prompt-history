# Sidenote 本地划词集成

提示词历史仍负责原生划词弹窗（复制 / 引用 / 引用到侧聊）。Sidenote 仍负责侧聊标签、历史、待发批注及结论回流。点击「引用到侧聊」只建立 Sidenote 待发批注，不自动发送，也不要求填写注解。普通「引用」仍走提示词历史。

本地集成基于上游 Sidenote v0.8.7；不改 DSH 或 Better Sidebar。Sidenote 客户端检测到提示词历史提供的菜单后，在自己的主对话选区浮层直接渲染三枚按钮，不再等待 DSH 原生 `quote` 插槽触发，所以适用于 Sidenote 能识别的单段和跨段选区。不影响文档摘录栏及批注编辑器。此路径不受提示词历史的原生划词槽和旧侧聊兼容开关影响。引用由 Sidenote 重新校验选区和源会话，复用原生目标锁定和待发批注逻辑；Sidenote 拒绝时保留选区，不悄悄转投 beta。

顶栏「侧边」入口在会话标题区，紧跟「工作台」，在后台任务之前；不再占右上角工具区。仅调整入口位置，不影响 `/side` 或划词。

主会话的待发引用通过 Sidenote 接入原生发送：正文为空也可以手动发送，不预填提问、不自动提交；宿主接受后只清除该批未修改的引用，拒绝时保留。两插件需配套更新。

## 从源码重放

检出 [Sidenote v0.8.7](https://github.com/g-yixuan/dsh-sidenote/tree/v0.8.7)，在其仓库根目录运行 `git apply --check`，再用 `git apply` 应用本仓库的 [Sidenote 补丁](../patches/sidenote-0.8.7-prompt-history.patch)。按 Sidenote 上游指南安装依赖、执行架构检查、类型检查、构建和测试，然后与本仓库的提示词历史配套打包。本仓库不保存上游源码副本或本地安装包。

本地包与上游市场包不同。市场更新可能覆盖桥接；回退请使用匹配的一对旧包（Sidenote 0.8.7、提示词历史 1.13.0-local.session-history.3），不需要删除会话或本地存储。
